# ACC-051 — QA-only saved typed view

Parent #19 (a9fb5206), source b687f134. Additive Jazz migration 7ddacb95394d to ed9b0d151df4; the persisted parent fixture includes typed record v8 and its receipt/event. A saved view is a definition over canonical records, never a materialized copy. Both permission variants deny direct typedViews CRUD.

The signed-in browser query needs the scoped share bearer credential, not board membership. MCP needs the same share AND live board-scoped board:read admission, checked before and after the shared query. Share creation/revision/revocation requires owner authority. SQL stores a token digest and version, not the raw share token. Signed continuation binds the subject, channel, share/version, view/version, schema, query and last sort key/record ID. Authorization is checked on every page and rechecked before returning data. Neither cursor nor share creates a board member or OAuth grant.

Demo items: Title-only, prefix Demo, ascending Title, record UUID tie-breaker, page size one. Filtered and nonexistent exact record IDs share the same denial. Hidden projection/sort/filter denied. More than 500 canonical records is an explicit VIEW_DATASET_LIMIT_500 error, not a partial total. Cursor payload size permits the existing 2000-character Title contract including JSON escaping. Cursors are signed, not encrypted, and contain only allowed sort-key and scope metadata. Pages are not a historical snapshot: concurrent record edits can move rows across the cursor, skip or repeat rows, or change totals. Revising the view invalidates the cursor; share revocation denies even a previously valid cursor.

Reproduce with frozen install, focused typed-shared-view, typed-view-migration, typed-record-patch and typed-record-migration tests; private CI with gate off and on; pnpm verify. The real browser proof uses authenticated HTTP with virtual passkeys, including an independent nonmember recipient, not a native grid or share panel. The separate read-only MCP client exercises actual OAuth. No workspace backfill, production capability expansion, general query engine or UI editing. No production deployment; physical passkeys and installed ChatGPT acceptance remain open.
