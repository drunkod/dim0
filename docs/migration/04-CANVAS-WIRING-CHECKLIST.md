# Canvas wiring checklist: Dim0 to Jazz

This remains a migration map, not an integration-complete claim. In the current development branch, the Dim0 React canvas has an **opt-in** Jazz adapter (`VITE_DIM0_JAZZ_CANVAS=1`) that bypasses both old sync hooks. The private server now exposes a separately authenticated live Jazz query as SSE (`private-canvas-stream.ts`), while versioned REST operations write to Jazz. The transport is not yet proven by real two-browser Dim0 acceptance, and it has **no durable offline outbox**. The original HTTP canvas CRUD endpoints alone were never a live subscription, and numerous non-canvas write paths remain unmigrated.

## Minimum cutover gates

- Verify conversion preserves Dim0 IDs, `graphUid`, note/document/link type, `_storedColors`, mini-app payload properties, and link endpoints.
- Verify local edits, remote edits, agent writes, off-scene writes, deletes, and nested-layer cascades each have a single durable write path.
- Verify optimistic concurrency: stale `expectedVersion` produces a recoverable conflict and never silently drops a newer edit.
- Verify initial load, offline reopen, reconnect catch-up, and two-client live observation. An HTTP snapshot test is not a live-subscription test.
- Keep the existing relay or implement a Jazz subscription before removing `use-ws-collab`/`useBoardSyncV2` live paths.
